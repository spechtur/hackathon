Feedback-Regel: eine Sache, die schon gut ist · eine Idee für den nächsten Schritt · eine ehrliche Frage.

Diesen Code auf den Beamer. Die Klasse scannt ihn und bekommt damit drei Dinge auf einmal: den aktuellen Schritt, den laufenden Countdown und die Werkzeuge, die du eingestellt hast. Wer die Seite schon offen hat, tippt einfach unten auf die Schrittnummer.

Den Countdown enthält der Code nur, solange der Timer läuft. Starte ihn also, bevor du scannen lässt — dann läuft der Balken auf allen Geräten sekundengenau gleich.

Adresse der Seite

Füllt sich selbst aus, sobald die Seite über eine echte Adresse läuft. Solange die Datei nur auf deinem Gerät liegt (file://…), bleibt das Feld leer und der Code funktioniert nicht — die Klasse käme nicht an deinen Laptop heran.

Alles hier gilt sofort — und wird über den QR-Code auch an die Klasse weitergegeben. Dauerhaft speichern lässt es sich mit dem Knopf ganz unten.
